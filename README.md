# Rolling the Stone — Sisyphus Over Time

**C C 303: Introduction to Classical Mythology**  
**Dillon Quigley · Spring 2026**

## About the Project

A static website examining how the myth of Sisyphus changes over time: from an
ancient story about a cunning king punished for cheating death and the gods, to a
modern symbol of futile labor, endurance, absurdism, and meaning-making.

## Site

The project is now a single long-scrolling page: `index.html`. It has no navigation
links or separate myth pages; the argument, visuals, and source list all live on one
continuous page.

## Primary Sources To Use

- Homer, *Odyssey* Book 11, lines 593–600
- Homer, *Iliad* Book 6, lines 152–155
- Apollodorus, *Library* 1.9.3
- Hyginus, *Fabulae* 50 and 60
- Pausanias, *Description of Greece* 2.5.1

## Technical Details

Built with plain HTML, CSS, and JavaScript: no frameworks and no build step.
Open `index.html` directly in any browser to run locally.
